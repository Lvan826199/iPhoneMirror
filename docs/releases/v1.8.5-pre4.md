这是用于功能和兼容性测试的预览版。

### 新增与改进

- 新增日语界面，覆盖应用、驱动管理器、安装器和相关工具，并使用适合日文的字体。
- 支持关闭主窗口后收起至托盘，保留投屏会话、独立窗口和未保存的按键映射草稿；默认关闭此选项。
- 改进五种语言、浅色与深色主题下的大字号布局、滚动条、固定关闭按钮、键盘导航和辅助功能资源。
- 优化原画虚拟摄像头的颜色转换、USB 解码回读和帧队列，改善 60 fps 输出；OBS 建议启用视频采集设备缓冲。

### 修复

- 修复 USB 控制停止与重试的资源竞争、多设备恢复枚举、解码器候选回退和慢启动等待。
- 完善 Cryptex/Personalized DDI 回退及媒体认证健康检查，避免失效连接继续报告控制就绪。
- 修复无线宿主清理、启动失败退避、DLNA 降级恢复，以及 HLS 异常退出被误判为播放完成。
- 录制文件发布失败时保留已完成成品，支持保存重试和重启恢复，防止后续录制覆盖未保存文件。
- 修复精简模式全屏尺寸、设置面板中的 F11/Esc、蓝牙 F9 输入切换、更新交接和音频欠载恢复。
- 改进 Apple USB 支持安装的日志失败重试、首次设置恢复、设备绑定及并行媒体输出状态。
- 应用与驱动管理器版本统一为 1.8.5-pre4。

### 验证范围

自动构建执行原生、Python、应用逻辑、驱动及本地化检查；GitHub 托管环境跳过需要交互桌面的 WPF 运行时测试。
本地记录包含五语界面、安装与卸载、真实 USB 投屏和控制及原画虚拟摄像头验证。单台设备的性能结果不代表所有设备；无线控制仍受 RemotePairing 凭据限制，未计为通过。详细范围见仓库内 2026-10-28 至 2026-10-29 的验证文档。

### Added

- Add Japanese localization across the app, driver manager, installer, and related tools, with Japanese font selection.
- Add optional close-to-tray behavior that preserves projection sessions, independent windows, and unsaved keyboard mapping drafts; disabled by default.
- Improve large-text layouts, scrollbars, fixed close buttons, keyboard navigation, and accessibility resources across five languages and both themes.
- Optimize native-resolution virtual camera conversion, USB decoder readback, and frame queues for smoother 60 fps output. Enable video capture device buffering in OBS for best results.

### Fixed

- Fix USB control stop/retry ownership, multi-device recovery enumeration, decoder fallback candidates, and slow-start readiness waits.
- Improve Cryptex/Personalized DDI fallback and media authentication health checks so failed sessions cannot keep reporting control readiness.
- Fix wireless host cleanup, startup backoff, DLNA degraded recovery, and HLS failures incorrectly reported as successful playback completion.
- Preserve completed recordings when publication fails, allow save retries and recovery after restart, and prevent overwriting unsaved recordings.
- Fix compact-mode full screen, F11/Esc with settings open, Bluetooth F9 input switching, update handoff, and audio underrun recovery.
- Improve Apple USB support installation retries after logging failures, setup restoration, device binding, and parallel media output state.
- Align application and driver manager versions at 1.8.5-pre4.

### Notes

Automated builds check native code, Python, application logic, drivers, and localization; GitHub-hosted runners skip WPF runtime tests requiring an interactive desktop.
Local validation records cover five-language UI layouts, installation and removal, real USB capture and control, and native-resolution virtual camera output. Performance on one device is not a guarantee for every device. Wireless control remains blocked by RemotePairing credentials and is not counted as passed. See the repository validation documents dated October 28–29, 2026 for scope and evidence.

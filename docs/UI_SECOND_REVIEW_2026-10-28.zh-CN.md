# UI 再审查与修复

日期：2026-10-28。检查普通文字、200% 文字、浅色和深色主题、不同语言和缩小工作区，结合实际 WPF 窗口渲染图、控件几何、状态变化和关闭行为。

## 本轮发现并修复

1. **更新页版本标签与关闭按钮重叠。** 固定关闭层移走原关闭按钮后，原先的 Auto 列失去宽度，版本标签占用了关闭位置。现在保留 40 DIP 的操作列，并检查版本标签与固定关闭按钮的实际边界不相交。
2. **高级 USB 设置的分辨率输入框在 200% 首屏不可见。** 长说明排在输入前，输入框被挤到滚动区域下方。现在先展示输入和相邻错误反馈，再展示详细帮助；验证失败时把反馈滚入视口。回归检查默认输入框和无效输入后的错误提示都可见。
3. **蓝牙配对提示在大字号下过窄、过长。** 状态切换和内容测量反复把宽度重置为 520 DIP，覆盖了共享大字号窗口适配。现在按实际文字倍率调整阅读宽度，200% 时为 702 DIP，并仍受工作区限制；连接成功后保留该宽度，按内容缩短高度。
4. **审查相册混入上轮中途截图。** 部分 200% 关于页与输出页截图早于页签等宽修改。相册中这两组主窗口及独立弹窗已用本轮截图更新；其余未修改窗口沿用原证据，来源逐组记录于 `provenance.json`。
